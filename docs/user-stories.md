# User Stories

1. As a visitor, I should be able to register an account.
2. As a registered user, I should be able to log in and log out.
3. As a visitor, I should be able to view a list of movies.
4. As a visitor, I should be able to view detailed information about a movie.
5. As a visitor, I should be able to search movies by title.
6. As a visitor, I should be able to browse movies by genre.
7. As a logged-in user, I should be able to create, edit, and delete my reviews for a movie.
8. As a visitor, I should be able to read reviews posted by other users.
9. As a logged-in user, I should be able to comment on reviews.
10. As a logged-in user, I should be able to like and unlike reviews.
11. As a logged-in user, I should be able to view and update my profile information.
12. As a logged-in user, I should be able to add and remove movies from my Watchlist.
13. As a logged-in user, I should be able to mark movies as watched and view my watched movies list.
14. As a user, I should only be able to edit or delete my own reviews.
15. As a visitor, I should not be able to rate movies or create reviews and comments without logging in.
16. As an admin, I should be able to add, update, and delete movies.
17. As a visitor, I should be able to view the cast and crew associated with a movie.
18. As a visitor, I should be able to view a person's profile and filmography.
19. As a logged-in user, I should be able to create, edit, and delete custom movie lists.
20. As a logged-in user, I should be able to add and remove movies from my custom movie lists.
21. As a visitor, I should be able to view public movie lists created by other users.
22. As an IMDb Pro user, I should be able to link my account to a professional profile.
23. As an IMDb Pro user, I should be able to update my profile picture, and primary profession.
24. As an IMDb Pro user, I should be able to view and manage credits associated with my professional profile.
25. As an admin, I should be able to add, update, and delete people and credits.
